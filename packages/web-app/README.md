# @insight-studio/web-app

Web application for Insight Studio

## Development

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```

Visit http://localhost:5173

## Build

```bash
pnpm build
```

## Features

- ✅ Interactive chart generation
- ✅ Real-time preview
- ✅ AI-powered insights
- ✅ Modern UI with React
- ✅ Full SDK integration
